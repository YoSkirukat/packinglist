# Packing List — поставки из Китая

MVP-сервис учёта поставок : загрузка packing list из Excel, таблица коробок и товаров, доступ по ролям.

## Стек

- Next.js 15 (App Router) + TypeScript + Tailwind CSS
- Prisma + SQLite
- ExcelJS для разбора packing list

## Быстрый старт

```bash
npm install
npm run db:push
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Первый вход: логин `admin`, пароль `admin` (или значение `ADMIN_PASSWORD` из `.env`).

Пункт **Пользователи** виден и доступен только администратору.

## Что уже есть

- Авторизация, роли admin / user
- Создание поставки
- для отображения изображений товаров создать в корне папку pictures и хранить в ней изображения товаров с кодом или артикулом в названии (любой формат изображения)
- Загрузка packing list (`.xlsx`) и таблица позиций
- Журнал действий: кто создал поставку и кто загрузил файл

## Дальше по шагам

- Сопоставление названий поставщика с вашей учётной системой
- Загрузка файла остатков
- Перемещения со склада партнёра на свой склад
